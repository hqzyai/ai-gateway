ENDPOINTS

对外能力一览

POST/v1/images/generations

文生图；也可通过 JSON 的 image 字段执行图生图。

POST/v1/images/edits

OpenAI 兼容的图片编辑入口，上传一张或多张图片。

POST/v1/videos

创建异步视频生成任务，立即返回 queued 状态与 video_id。

GET/v1/videos/{video_id}

查询任务状态与 usage；完成后 status 为 completed。

GET/v1/videos/{video_id}/content

任务完成后下载视频二进制内容；未完成会返回错误。

GET/v1/videos?custom_llm_provider=volcengine&limit=20

列出火山视频任务；支持 limit 与 extra query，不支持 after / order。

DELETE/v1/videos/{video_id}

取消或删除上游任务，响应映射为 cancelled。

不支持remix · characters · video edits · extensions

LiteLLM 有这些通用路由，但当前火山 Seedance 2.0 适配器不实现。

Python · OpenAI SDK 兼容调用
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["LITELLM_API_KEY"],
    base_url="http://<gateway-host>:4000/v1",
)

result = client.images.generate(
    model="doubao-seedream-5-0-260128",
    prompt="一只白色机械猫站在雨后的上海街头，电影感",
    size="2048x2048",
    response_format="url",
    extra_body={"output_format": "png", "watermark": False, "seed": 42},
)
print(result.data[0].url)

queued

任务排队中，稍后轮询。

in_progress

正在生成，继续轮询。

completed

failed

ERROR PLAYBOOK

常见错误与处理

Budget has been exceeded

虚拟 Key、用户或团队预算不足。提高对应预算，或换用有余额的 Key；异步视频任务可能已在火山开始，预算应在创建前留足。

模型未配置 / 不在列表

实现支持不等于当前代理已路由。到模型管理添加模型，并使用暴露给客户端的 model_name。

分辨率不支持

Fast / Mini 不支持 1080p、4K；切换到 480p / 720p，或改用完整版 Seedance 2.0。

视频仍是 queued / in_progress

这不是失败。指数退避轮询状态；只有 completed 后再调用 content 下载，failed 时停止。

不支持的参数

默认会返回明确错误。若网关开启 drop_params，未知字段可能被丢弃；生产调用应只传本文档列出的字段。

视频 ID 无效

必须保存 LiteLLM 返回的完整编码 ID。不要只截取火山原始 task id，否则模型和视频输入计费上下文会丢失。

!

安全边界

客户端只持有 LiteLLM Virtual Key。火山 ARK_API_KEY / VOLCENGINE_API_KEY 只配置在网关服务端；不要写入浏览器代码、移动端包、HTML 文档、日志或仓库。本文所有示例均使用 $LITELLM_API_KEY 占位符。
